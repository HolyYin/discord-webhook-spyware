# Configuration

To make the script work, you must insert your Discord webhook URL into the `WEBHOOK_URL` constant.

# How It Works

The script creates a local folder named `outputs_ds_webhook`, where it temporarily stores:

* A `.txt` file containing captured keystrokes
* A webcam image
* A screenshot

These files are automatically deleted shortly after the data is processed.

You can also modify the **cycle interval**, measured in seconds, to control how frequently the script collects and processes the data.
